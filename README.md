# hawk5

ARM 固件项目，主界面应用名为 **「1 Motorola R7」**。

## 构建 (Building)

```bash
git clone <repo_url>
cd hawk5
make
```

## 烧录 (Flashing)

使用 k5prog 等工具烧录 `bin/firmware.bin`。

## 1 Motorola R7 界面说明

![ee84ff42b8b0da73dc8035214c5b4101](https://github.com/user-attachments/assets/45a67772-185f-40d6-b84b-e3dd5444cf30)


主界面自上而下分为四块：**顶部菜单栏**、**中间方框**、**信息栏（计时 + 亚音）**、**底部两个方框**。

### 顶部菜单栏

| 区域 | 说明 |
|------|------|
| 左侧 | 天线图标；5 格信号条（随 RSSI 显示 1～5 格） |
| 中间（x=20 起） | 直频符号（同频时为竖线-箭头-竖线，两条竖线在横线下、高 5px）、功率（如 UL/L/M/H）、带宽、静噪类型、静噪值、步进；直频时功率与符号间隔、功率右侧状态文字整体左移以收紧宽度；本页不显示芯片、增益、调制 |
| 右侧 | 电池/电量；状态图标区（EEPROM、存储满、监听、广播、上变频、按键锁等） |

### 菜单栏下一行

**已移至中间框与底部菜单之间**，见上文「信息栏」：第一行为计时（右对齐），第二行为亚音（有则显示 R/T）；芯片名不再显示于该区域。

### 中间方框

| 区域 | 说明 |
|------|------|
| 左侧竖条 | 宽度 6px；无信号时实心，有信号时空心，与右侧大框共用一条竖线（1 像素分隔）；有/无信号时竖条宽度一致 |
| 框内右上角 | 接收灵敏度 `±数字 dBm` 或 `-- dBm`（相对框右缘右移 1px） |
| 第一行 | 小字反色标签（MR 三位数 或 VFO）+ 信道名（Medium 字体） |
| 第二行 | 大号频率 + 两位小数，上部分向右倾斜（顶部约 3px，向下渐变） |

### 信息栏（中间框与底部菜单之间）

| 行 | 说明 |
|------|------|
| 第一行 | 计时，格式 `分:秒`（上电运行时间），**右对齐** |
| 第二行 | 亚音（仅当有接收或发射亚音时显示）：`R接收码` 和/或 `T发射码`，贴右缘 |

### 底部方框

| 区域 | 说明 |
|------|------|
| 左侧 | 「Menu」反色，进入主菜单 |
| 右侧 | 当前调制方式（FM/AM 等）反色；两框等高，中间竖线分隔；框向上增高 2px，框内文字略下移 1px |

## 操作说明

### 按键定义

| 按键 | 短按 | 长按 |
|------|------|------|
| **Menu** | 进入「运行应用」列表（选择主界面、信道、FC、频谱等） | 进入**设置**菜单 |
| **Exit** | 退出当前应用/返回上一级；若在监听则关闭监听 | — |
| **↑ / ↓** | 切换信道（信道模式）或步进调频率（VFO 模式） | — |
| **0～9** | **0**：打开/关闭射频参数小菜单；**1～9**：VFO 模式下进入频率输入（当前键为第一位数字）；**信道模式**下为数字选信道（见下方） | 见下方数字键长按 |
| **# (F)** | 进入信道配置（CH cfg） | 切换**按键锁**（keylock） |
| **\* (Star)** | 进入 Loot（已存频率/信道列表） | — |
| **PTT** | 发射（按下）/ 松开停止发射 | — |
| **侧键 1** | 切换**监听模式**（打开静噪） | 切换频谱/显示单位（与侧键 2 相反方向） |
| **侧键 2** | 开关**手电筒** | 同上 |

**主界面（1 Motorola R7）数字键长按：**

| 按键 | 功能 |
|------|------|
| 1 | 信道列表（按波段过滤） |
| 3 | VFO ↔ 信道模式切换 |
| 6 | 功率档位 + |
| 0 | 调制方式 + |

**其他：**

| 说明 | 操作 |
|------|------|
| 信道模式数字选信道 | 短按 0～9，顶部菜单栏显示「Select: xx」，可**连续输入**多位信道号（1-based：输入 1 到 1 号信道），按 **Menu** 或 **PTT** 确认跳转；**Exit** 退格或退出输入 |
| 按键锁 | 设置中开启后仅 PTT、侧键 1/2 可用；长按 **# (F)** 解锁/加锁 |

### 主菜单（Menu 短按）— 运行应用

**操作**：↑/↓ 选择，**Menu** 确认进入，**Exit** 返回。

| 应用名 | 含义 |
|--------|------|
| 1 Motorola R7 | 主 VFO/信道界面 |
| Channels | 信道列表 |
| FC | 频率校准（Freq Counter） |
| Spectrum | 频谱/扫描 |
| CH Scan | 信道扫描 |
| Band Scan | 波段扫描 |
| ABOUT | 关于固件 |

---

### 设置菜单（Menu 长按）— Settings

**操作**：↑/↓ 选择，**Menu** 进入子菜单或确认，**Exit** 返回；有数值的项用 **\*** / **#** 减/加。

| 主项 | 说明 / 子菜单内容 |
|------|-------------------|
| Scan | 扫描相关 → SQL（静噪开/关时间）、FC t、Listen t/o、Stay t、Skip X_X |
| Radio | 电台相关 → DTMF decode、Filter bound、SI power off、STE、Tone local、Roger、Multiwatch、Mic、Freq corr |
| Display | 显示 → Contrast、BL max/min/time、BL SQL mode、CH display、Level in VFO |
| Battery | 电池 → Bat type、Bat style、BAT cal（校准） |
| Beep | 按键提示音 |
| Main app | 开机默认启动的应用 |
| Lock PTT | PTT 锁（仅锁 PTT 等） |

---

### 主界面内寄存器/参数小菜单

**进入/退出**：主界面**短按 0** 打开或关闭。

| 操作 | 说明 |
|------|------|
| ↑/↓ | 选择参数（依芯片：Radio、增益、带宽、静噪、调制、步进、AFC、频偏、功率等） |
| \* / # | 减小 / 增大当前值 |
| Exit 或再按 0 | 关闭小菜单 |
